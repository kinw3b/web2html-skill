# Design Library reference

`design-library.html` is the frozen HTML export of the `Design Library`
artboard in the canonical Web2HTML Library Paper file, captured on 2026-08-20.
It is the visual gold for step 1.4. Runtime code does not fetch the Paper URL.

Step 1.4 populates the tokenized shells in `../foundations/` with each site's
mined values. Keep those shells structurally aligned with this local export:
header, colour, typography, spacing, then elevation and radii.

Refresh intentionally (Paper Desktop must be open):

```bash
node "1.2 url-to-paper/scripts/capture-reference-frames.mjs"
```

Source provenance: Paper file `01M04TZDSPQDTXS5YCRKQD66WQ`, page `1-0`.
