Run timeline

Follow the work as it moves.

1.1

Scope the page and keep the files honest

Open the live board first. Scrape the homepage — images plus Latin fonts only. Do not write rebuild HTML.

named, checked
1.2

Capture every breakpoint to Paper

Capture the homepage and Navigation at 1600, 768, and 390. Store a source clip next to each lander. Prove desktop geometry before moving on.

1600 · 768 · 390
1.3

Create the Design Library + Tokens

Mine one set of colors, type, and spacing from the Paper frames. Bind them back without moving layout. Then copy unique buttons and cards from desktop into the Buttons and Components frames, and author button hover from source CSS.

named once
1.4

Human checkpoint

Review all three sizes, Navigation, Buttons, Components, and the Design Library in Paper. Pin every problem. Capture Tool stays optional leftover hover. Marking done prints the session 2 prompt.

walk Paper, then sign off
2.1

Emit the Design System

Write rebuild/design-system.html and tokens.css from the signed Design Library. Token contract, not the ship.

system before page
2.2

Author the homepage from Paper

Author one semantic, responsive first pass from Paper desktop using the 2.1 tokens. Writes index-semantic.html. No new palette, fonts, or copy. file:// only.

Paper is the brief
2.3

Validate each section against Paper

Pull the numbered 1.2 section clips (01-slug.png at 1600 / 768 / 390) and compare each rebuild band to those files plus index-raw. Serial or at most two workers. No live Paper MCP. Recipe: section-23-paper-loop.md. qa/paper-measure/clip-compare.json required. No invented 1024 or 1320.

disk gold · max 2
2.4

Sign-off, then Session 3 polish

Sign off the 2.4 lock with TAGS on. Continue starts Session 3 polish at 3.1. index-polish.html does not exist until 3.1 starts — it is not polished yet.

TAGS, then 3.0
3.1

Session 3 polish starts

First action copies index.html to index-polish.html. That copy is not polished until 3.1–3.3 finish. Then a11y, contrast, and anti-slop on the copy only.

copy, then polish
3.2

Hover, GSAP, and guidelines

Sequential GSAP reveals as each section crosses 25% from the viewport bottom, plus source-CSS button hover, a painted burger drawer, FAQ accordion, nav dropdowns, and guidelines a11y. No layout restyle.

hover · GSAP
3.3

Semantics and SEO

Sweep landmarks, SEO, and images. Earlier hover work stays out of scope.

semantics · SEO
3.4

Human checkpoint

Compare the 2.4 index.html with index-polish.html, then sign off. The homepage run can stop here. Optional Phase 4 imports the rest of the site into Paper.

compare, then optional 4.0

5.1

Scaffold Astro + shared chrome

Optional. Create astro/ from the signed rebuild CSS, fonts, images, and scripts. Pull Header, Footer, and every Paper-backed component once from the polish homepage; convert the homepage to index.astro. No server.

astro/ · Header · Footer · once
5.2

Author each interior body

Optional. One worker per page, two at a time. Only the <main> of src/pages/{slug}.astro on the shared chrome. Paper is the brief. Raw dumps only in rebuild/.

sub-agents · max 2
5.3

Validate desktop clips

Optional. astro build, then compare each built page in astro/dist to the 4.2 1600 section clips. Fix the .astro body, rebuild, reshoot. Disk only. No Paper MCP.

desktop gold · dist
5.4

Make interior pages responsive

Optional. Capture live 768 and 390 clips, reshoot the built pages, then compare. Real media queries. No extra Paper frames.

live 768 · 390
